C5FG0130P0Dépose - Repose : Système audio USB BOX
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage
Figure : e5ap30wd
[1] Outils de dégarnissage (-).1350.
2. Dépose
Débrancher la batterie .
2.1. Support système audio USB BOX ( direction à gauche )
Figure : c5fg08sd
Déposer l’autoradio  (suivant équipement).
Déclipper - Dégager : Le support système audio USB BOX (1) ; À l’aide de l’outil [1].
Déconnecter le connecteur ( en "a" ).
Déposer : Le support système audio USB BOX (1) (Sur un établi ).
2.2. Système audio USB BOX - Prise USB BOX ( direction à gauche )
Figure : c5fg08td
Déposer les vis (3).
Dégager : Le système audio USB Box (2).
Déconnecter les connecteurs ( en "b" ).
Déposer : Le système audio USB Box (2).
Déclipper : La prise USB BOX (4) ; À l’aide de l’outil [1].
Déconnecter : Le connecteur de la prise USB BOX (4) ( en "c" ).
Déposer : La prise USB BOX (4).
2.3. Support système audio USB BOX ( direction à droite )
Figure : c5fg08ud
Déposer l’autoradio  (suivant équipement).
Déclipper - Dégager : Le support système audio USB BOX (5) ; À l’aide de l’outil [1].
Déconnecter le connecteur ( en "d" ).
Déposer : Le support système audio USB BOX (5) (Sur un établi ).
2.4. Système audio USB BOX - Prise USB BOX ( direction à droite )
Figure : c5fg08vd
Déposer les vis (7).
Dégager : Le système audio USB Box (6).
Déconnecter les connecteurs ( en "e" ).
Déposer : Le système audio USB Box (6).
Déclipper : La prise USB BOX (8) ; À l’aide de l’outil [1].
Déconnecter : Le connecteur de la prise USB BOX (8) ( en "f" ).
Déposer : La prise USB BOX (8).
3. Repose
Procéder dans l’ordre inverse des opérations de dépose.
Rebrancher la batterie.
ATTENTION : En cas de remplacement du système audio USB BOX (2 -6) : Initialiser avec l’outil de diagnostic .
Vérifier le fonctionnement des équipements.
