D5AG0111P0Dépose - Repose : haut-parleurs (avant et arrière)
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
1.1. haut-parleurs avant
Déposer le panneau de porte avant .
Figure : d5am03dd
Déposer les vis (2).
Dégager le haut-parleur (1).
Figure : d5am03ed
Déconnecter le connecteur  (en "a").
Déposer le haut-parleur (1).
Figure : d5am03fd
Chasser les clous de rivets avant le perçage.
Percer les têtes de rivets (3) ; À l’aide d’un foret Ø 6 mm.
Déposer : Le support du haut-parleur (4).
Percer les corps de rivets restants.
NOTA : Aspirer le fond de la porte pour extraire les déchets des rivets.
1.2. haut-parleurs arrière
Déposer : Le support tablette arrière .
Figure : d5am03gd
Déposer :
  • Les vis (5)
  • Le haut-parleur (6)
1.3. Tweeter de planche de bord
Figure : c5fm0ndd
Déclipper : Les tweeters de planche de bord (7) ; À l’aide d’un tournevis fin.
Déconnecter : Les tweeters de planche de bord (7) (en "b").
Déposer : Les tweeters de planche de bord (7).
2. Repose
ATTENTION : Remplacer systématiquement les agrafes défectueuses.
ATTENTION : Procéder à l’étanchéité du support de haut-parleur (1), (6).
Procéder dans l’ordre inverse des opérations de dépose.
Vérifier le fonctionnement électrique des équipements.
