C4AG010VP0Dépose - Repose : Capot moteur
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
1.1. Capot moteur
Ouvrir le capot moteur.
Désaccoupler : Le tuyau de lave-vitres.
Figure : c4am0pfd
NOTA : Deux personnes sont nécessaires pour effectuer l’opération suivante.
Déposer :
  • Les écrous (1)
  • Le capot moteur (2)
1.2. Bras d’articulation de capot
Figure : c4am0pgd
Déposer ( de chaque côté) :
  • Les vis (4)
  • Le bras d’articulation de capot (3)
2. Repose
2.1. Bras d’articulation de capot
Reposer ( de chaque côté) :
  • Le bras d’articulation de capot (3)
  • Les vis (4) ; Serrer à 2,5 m.daN
2.2. Capot moteur
NOTA : Deux personnes sont nécessaires pour effectuer l’opération suivante.
Reposer :
  • Le capot moteur (2)
  • Les écrous (1)
Serrer les écrous (1) et les desserrer d’un quart de tour.
Fermer le capot moteur.
Effectuer le réglage des jeux et affleurements .
Ouvrir le capot moteur.
Serrer les écrous (1) à 1 m.daN.
Accoupler : Le tuyau de lave-vitres.
Fermer le capot moteur.
Vérifier le fonctionnement des équipements.
