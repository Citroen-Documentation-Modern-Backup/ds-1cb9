C5GS0115P0Déshabillage - Habillage : Siège arrière (Rang 3)
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage
Figure : e5ap30wd
[1] Outils de dégarnissage (-).1350.
2. Opération préliminaire
Déposer les sièges arrière individuels (Voir notice d’utilisation).
3. Déshabillage
3.1. Carters
Figure : c5gm10qd
Déposer (de chaque côté) :
  • La vis (2)
  • Le carter (1) ; À l’aide de l’outil [1]
3.2. Brin de boucle
Figure : c5gm10rd
Déposer :
  • La vis (3)
  • Le brin de boucle de ceinture de sécurité (4) ; Dégager l’indexage (en "a")
3.3. Appui-tête - Enjoliveur de commande
Figure : c5gm10sd
Déposer :
  • L’appui-tête (5)
  • L’enjoliveur de commandes (6) (Tirer suivant flèche)
3.4. Coussin de dossier : Sièges latéraux
Figure : c5gm10td
Actionner la fermeture éclair du coussin de dossier (7) ( en "b").
Déclipper le verrouillage du coussin garni de dossier (7) ( en "c") ; À l’aide d’un tournevis plat.
Figure : c5gm10ud
Passer la main sous le coussin de dossier (7) afin d’atteindre les guides appuis-tête (8).
Déclipper les guides d’appui-tête (8) ( en "d") ; À l’aide d’un tournevis plat.
Déposer les guides d’appuis-tête (8).
Figure : c5gm10vd
Déposer le coussin garni de dossier (7) (suivant flèche ).
3.5. Coussin d’assise
Figure : c5gs02hd
Déclipper les verrouillages du coussin d’assise (8) (en "e") ; À l’aide de l’outil [1].
Déposer le coussin garni d’assise (8).
Figure : c5gs02id
Déclipper les enjoliveurs (9) (en "f") ; À l’aide de l’outil [1].
Déposer les enjoliveurs (9).
Figure : c5gs02jd
Déposer :
  • Les vis (10)
  • Le système d’ancrage arrière (11)
Figure : c5gs02kd
Déposer (de chaque côté) :
  • Les vis (12)
  • Le système d’ancrage avant (13)
Figure : c5gs02ld
Déclipper la nappe de dossier (14) ( en "g").
Déposer la nappe de dossier (14).
4. Habillage
Procéder dans l’ordre inverse des opérations de déshabillage.
Figure : c5gs02md
NOTA : Commander 2 curseurs (15) en pièces de rechange.
Fermer la fermeture éclair (16) ; À l’aide du curseur (15) ( de chaque côté).
Figure : c5gs02nd
Cacher le curseur (15) sous le coussin de dossier (7).
Les vis (3), (10), (12) à 2,5 m.daN.
Vérifier le fonctionnement des équipements.
