C5CG010PP0Dépose - Repose : Vitre mobile de volet arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage
Figure : e5ap30wd
[1] Outils de dégarnissage (-).1350-ZZ.
2. Dépose
Ouvrir : La vitre mobile de volet arrière .
Débrancher la batterie .
2.1. Vitre mobile de volet arrière
Figure : c5cm05dd
Dégager le faisceau (1) (en "a") ; À l’aide de l’outil [1].
Déconnecter le connecteur  (en "b").
Figure : c5cm05ed
NOTA : 2 personnes sont nécessaires pour effectuer les opérations suivantes.
Maintenir la vitre mobile de volet arrière ouvert ; À l’aide d’un support.
Dégrafer : L’équilibreur (2) (en "c") (Opération symétrique).
Figure : c5cm05fd
NOTA : 2 personnes sont nécessaires pour effectuer les opérations suivantes.
Déposer :
  • La vis (4) (Opération symétrique)
  • La vitre mobile de volet arrière (3)
Figure : c5cm05gd
Déposer le bras d’essuie-vitre arrière .
Déposer :
  • La vis (5)
  • La fixation d’équilibreur (6)
Déposer l’écrou à embase (7).
NOTA : Procéder de la même manière pour l’autre côté.
Figure : c5cm05hd
Déposer :
  • Les écrous (8)
  • Le palier d’essuie-vitre arrière (9)
2.2. Charnières de vitre mobile de volet arrière
Figure : c5cm05jd
Déposer :
  • Les vis (11)
  • Les charnières de vitre mobile de volet arrière (10)
Figure : c5cm05kd
Déclipper et déposer : L’enjoliveur de charnières de vitre mobile de volet arrière (12) (en "d") ; À l’aide de l’outil [1].
NOTA : Procéder de la même manière pour l’autre côté.
3. Repose
Procéder dans l’ordre inverse des opérations de dépose.
Serrer :
  • Les vis (5) à 0,8 m.daN
  • Les écrous (8) à 1 m.daN
Vérifier les jeux et affleurements .
Rebrancher la batterie .
4. Réglages
Figure : c5cm05ld
Sur les charnières de vitre mobile de volet arrière (10), l’indexage est démontable (en "e").
NOTA : Il est cependant possible de supprimer les indexages, si besoin de réglage supplémentaire (affleurement) en déposant les charnières.
Régler jeux et affleurements ; À l’aide des vis (11).
Figure : c5cm05md
Régler jeux et affleurements ; À l’aide des vis (4).
Serrer :
  • Les vis (4) à 0,9 m.daN
  • Les vis (11) à 0,8 m.daN
Vérifier l’étanchéité de la vitre mobile de volet arrière (3).
Vérifier le fonctionnement des différents équipements.
